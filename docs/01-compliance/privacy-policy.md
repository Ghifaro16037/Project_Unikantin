# Kebijakan Privasi UniKantin
Versi M01 (Data Lokal)

## 1. Data yang Kami Simpan
Aplikasi UniKantin hanya menyimpan data riwayat pemesanan makanan, batas anggaran bulanan, dan hash PIN Anda secara lokal, & data transaksi.

## 2. Di Mana Data Disimpan
Seluruh data berada di dalam penyimpanan aman (secure storage) perangkat Anda sendiri tanpa server luar.

## 3. Siapa yang Bisa Melihat
Hanya Anda. Kami tidak memiliki akses ke data transaksi Anda.

## 4. Hak Anda
Anda dapat melihat, mengubah, mengekspor, atau menghapus seluruh data kapan saja dari menu Pengaturan.
